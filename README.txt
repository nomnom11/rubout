RUBOUT
A pencil-on-graph-paper twin-stick shooter. Enemies are numbers, weapons are math operations.

HOW TO RUN
Double-click index.html. It opens in any modern browser. No install needed.
(The handwriting fonts load from Google Fonts when you are online; offline it falls back to a system font.)

HOW TO PUBLISH
Upload index.html to any static host (GitHub Pages, Netlify, itch.io as an HTML5 game, etc.).

CONTROLS
Move: WASD / arrows   Aim+fire: mouse   Switch operation: 1-9, Q/E, wheel
Pause: P/Esc   Info screen: I   Touch: left thumb moves, right thumb aims
